⚠ Educational tool — demonstrates how naive archive extraction writes files outside the target directory. Use only on systems you own or are explicitly authorized to test.

Leave the path empty to keep the file safely inside the extraction directory. Absolute overwrite paths get a standard ../../../../../../../../ prefix added automatically.
